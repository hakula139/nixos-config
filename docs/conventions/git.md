# Git

Follow the global Conventional Commits and PR doctrine, plus the `data/corp-domain.nix` ban in [AGENTS.md](../../AGENTS.md), which bites at commit time. This repo adds one rule of its own:

- **Scope** is the module name (`mihomo`, `secrets`, `system-manager`), the file (`flake`, `agents`, `readme`), or the host name (`us-2`, `wsl`, `devvm`) for host-scoped changes.
