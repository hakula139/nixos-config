## Claude Code

- **Prose polish**: a hook rewrites the Chinese prose in your Markdown, question text, and certain MCP fields before writing them, leaving English unchanged. It polishes each edited fragment without its surrounding sentence, so replace whole sentences or bullets and reread the result. Treat its output as final, using a replacement run from Bash to restore only substantive claims or qualifications it dropped, since an Edit would polish the restored text again. This hook, the formatter, and the comment gate run only on Edit and Write, so use those tools for repository edits even when auto mode suggests `sed` or a heredoc.
- **Bash**: never start the `command` field with a shell comment because that breaks permission pattern matching. Put explanations in the `description` parameter. In an isolated worktree, the guard refuses any command it cannot prove keeps git inside the worktree, including loops, substitutions, heredocs, and text that merely contains `git`, so write multi-step logic as a script in the worktree's gitignored build directory and run each git command on its own.
- **Web search**: native `WebSearch` needs a profile that enables it, while `WebFetch` always works.
- **IDE MCP** (`mcp__ide__*`): use `getDiagnostics` to check for language server errors and warnings. Use `executeCode` to run Python in Jupyter kernels when working with notebooks.
- **Agents**: use subagents for independent tasks and Agent Teams when peers need shared task state or direct messaging. Isolate parallel writers with `Agent({ isolation: "worktree" })`. A subagent spawning another agent omits `name` so that the new agent reports back to it, because in a team session a named agent joins the main session's team and reports to the team lead.
- **Waiting**: end the turn when nothing else is pending, because a background subagent's completion notification resumes you. To wait for a report file, CI, or a remote operation, start one `run_in_background` Bash command that exits when the condition holds or a time limit passes, since the harness resumes you when it exits. Reserve a `Monitor` watch for streams whose individual events matter, as it resumes you on every output line.
- **Compaction**: preserve the current task state, modified files, architecture decisions, code style requirements, and unresolved issues. After compaction, reread the project's AGENTS.md before continuing.
