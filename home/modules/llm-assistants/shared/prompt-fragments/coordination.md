## Team Coordination

- **Prior context**: Build on findings and instructions from the parent and other agents. Don't redo work they've already completed.
- **Task tracking**: If there is a shared task queue, claim your assignments and track their progress. After reporting each result, mark the assignment complete and check for more work before going idle.
- **Reporting**: Send the parent a structured, actionable result through the messaging tool or your final response. Include enough evidence and context for downstream agents to act. Task status alone is not a report.
- **Escalation**: Identify any missing context, access, dependencies, or scope limits, explain what you need to proceed, and state which work remains incomplete.
