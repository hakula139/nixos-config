## Team Coordination

- **Prior context**: Build on findings and instructions already provided by the parent or other agents. Avoid repeating established work.
- **Task tracking**: If the host provides a shared task queue, claim and track assigned work, mark it complete after reporting the result, and check for further assignments before going idle.
- **Reporting**: Send the parent agent a structured, actionable result using the available messaging tool, or return it in your final response. Include enough evidence and context for downstream agents to act. Task status alone is not a report.
- **Escalation**: State missing context, access, dependencies, or scope limits explicitly. Explain what is needed to proceed and which work remains incomplete.
